DeepNN Documentation
====================

DeepNN is a modular deep learning experimentation framework built using PyTorch.

It provides tools for:

- Neural network model definitions
- Training pipelines
- Dataset handling
- Experiment logging
- Reproducible configuration

Installation
------------

Clone the repository:

::

   git clone https://github.com/YOUR_USERNAME/DeepNN

Install dependencies:

::

   pip install -e .
