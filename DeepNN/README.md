# DeepNN

This project is a learning repository for deep learning using PyTorch.

The goal is to build neural networks from scratch and understand how
deep learning models work.

## Project Structure

DeepNN/
│
├── src/        Python source code
├── notebooks/  experiments and tutorials
├── data/       datasets
├── venv/       virtual environment
├── requirements.txt
└── README.md

## Installation

Clone the repository

git clone https://github.com/PattiMont96/DeepNN.git

Navigate into the project

cd DeepNN

Create virtual environment

python -m venv venv

Activate environment

Windows:
venv\Scripts\activate

Install dependencies

pip install -r requirements.txt

## Running the Code

python src/main.py

## Technologies Used

- Python
- PyTorch
- NumPy
- Matplotlib
